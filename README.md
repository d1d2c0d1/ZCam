# 🎥 ZCam — библиотека управления PTZ-камерами через Arduino + SBUS

**ZCam** — это библиотека для Arduino, которая позволяет управлять PTZ-камерами (например Tapotek KHP290G609) с пульта RC через SBUS (сигнал можно принимать как с полетного контроллера, так и напрямую с приемника/передатчика, главное, чтобы был SBUS Out пин и земля).  
С помощью ZCam вы сможете наклонять камеру вверх/вниз/влево/вправо, менять режим изображения, управлять зумом и другими функциями прямо с вашего пульта, даже если ранее этой поддержки небыло.

---

## ✅ Возможности

- Получение 16 каналов RC-пульта через SBUS.
- Реакция на изменение каналов через события (Event Handler).
- Управление PTZ-камерой Tapotek по UART.
- Гибкая система колбэков.
- Поддержка нескольких каналов в одном событии (Combined Events).
- Совместимость с Arduino Nano, UNO, Mega, Pro Mini и подобными AVR-контроллерами.
- Совместимость с Ardupilot и Pixhawk 6c/CUAV X7 и подобными.

## 🧰 Необходимое оборудование

| Компонент | Назначение |
|-----------|------------|
| **Arduino Nano / UNO / Mega** | Основной контроллер |
| **SBUS приёмник** (FrSky, Radiomaster, FlySky, Futaba и др.) | Приём каналов RC |
| **Инвертер сигнала SBUS** | Для правильного уровня логики на RX Arduino |
| **PTZ-камера Tapotek** (например KHP290G609) | Управление по UART |
| **USB-UART модуль** | Для вывода логов на ПК (не обязательно) |
| **Переключатель на RX линии** | Для отключения SBUS во время прошивки |
| **Полетный контроллер с SBUS выходом** | Для получения сигналов управления |

---

## ⚡ Что такое инвертер сигнала SBUS

**SBUS** — это инвертированный TTL-сигнал, то есть логика "1" и "0" поменяны местами.
Arduino не может напрямую читать такой сигнал, поэтому используется инвертер — небольшая схема на транзисторе или микросхеме, которая возвращает правильную логику.

Чтобы не мешать загрузке прошивки по USB, в линию RX ставят **переключатель**, который может временно отключать SBUS.

---

## 🔌 Подключение

```
SBUS приёмник ─► Инвертер ─► Arduino RX0 (Serial)
                  │
                  └─► Переключатель (SBUS / USB)

Камера UART ─► Arduino:
  RX → D2
  TX → D3

USB-UART модуль ─► Arduino (не обязательно, только для вывода логов):
  RX → D5
  TX → D6

Питание: 5V / GND
```

## ⚡ Важно перед началом работы

В **Mission Planner** (или ином GCS) в разделе Servo Outpus (если используете SBUS-Out) нужно выставить нужные выходы на соответствующие RCIN'ы (например: RCIN01).
Будьте внимательны, так как можнете случайно убрать выходы на моторы и назначить туда свои PWM выходы, что приведет к непредвиденным обстоятельствам.

## 💻 Установка Arduino IDE и библиотек

1. Скачайте [Arduino IDE](https://www.arduino.cc/en/software).
2. Установите и откройте программу.
3. Подключите Arduino к компьютеру через USB.  
   В меню **Инструменты → Порт (Port)** появится новый COM-порт (например `COM3`).
4. Если порт не появляется — установите драйвер **CH340** или **CP2102**.
5. Если Arduino Nano не прошивается — выберите:
   **Инструменты → Процессор → ATmega328P (Old Bootloader)**.
6. Установите библиотеку **SBUS** от *Bolder Flight Systems* через:
   **Скетч → Подключить библиотеку → Управлять библиотеками…**
7. Скачайте ZIP проекта **ZCam** с GitHub и добавьте:
   **Скетч → Подключить библиотеку → Добавить .ZIP библиотеку…** или вручную перейдя в папку Arduino библиоткеи (чаще всего в *C:\Users\{YOUR_USER_NAME}\Arduino\libraries* - внутри нужно создать папку ZCam и туда распоковать ZIP архив, внутри должна быть структура библиотеки)
8. После установки пример будет доступен:
   **Файл → Примеры → ZCam → ZCam_Test**.

## 🛠 Методы TapotekCamera

| Метод | Параметры | Описание |
|--------|------------|----------|
| `void setSerial(SoftwareSerial& ser)` | объект SoftwareSerial | Привязка UART интерфейса для урпавления камерой (нужно для общения Arduino с вашей камерой) |
| `bool centerPosition()` | — | Центрирование камеры |
| `bool sendGimbalMove(const String& direction)` | "up", "down", "left", "right", "stop" | Команда движения подвеса |
| `bool sendZoomIn()` | — | Увеличивать зум |
| `bool sendZoomOut()` | — | Уменьшать зум |
| `bool sendZoomStop()` | — | Остановить зум |
| `bool sendChangeIRColorMode()` | — | Переключить расцветку тепловизора (если камера поддерживает) |
| `bool sendChangeWindowMode()` | — | Переключить режим вывода окон (если две и более камер (тепловизр+ночная)) |
| `bool sendPitchToUp()` | — | Повернуть камеру вверх (безопасный метод) |
| `bool sendPitchToDown()` | — | Повернуть вниз (безопасный метод) |
| `bool sendGimbalMove("DIRECTION")` | `string` - "up","down","left","right" | Начать поворачивать камеру (внимание, если довернуть больше возможного, то камера уйдет в перезагрузку и будет потреблять около 8.5W, через несколько секунд она снова включится, это происходит из-за того, что камера уходит за границы возможного движения, будьте аккуратны с данными режимами, советую использовать sendPitchDown или sendCenterPosition) |

## ⚙️ События ZCam

Библиотека использует событийную модель.

Пример регистрации событий в блоке `setup() {... тут ...}`:

```cpp
zcam.addEventHandler("channel0", "", onZoomChange);
zcam.addCombinedEventHandler(pitchChannels, 2, +onPitchXYChange, 5, "pitchXY");
```

Каждое событие передаёт (пример описания функции для создания обработчика события):

```cpp
bool callback(const String& eventName, uint16_t channels[16], const String& condition);
```

## ⚡ Советы

- Если при загрузке скетча IDE выдаёт ошибку `avrdude: stk500_recv()`, переключите инвертер в режим **USB**.  
- Проверяйте скорость порта: для логов используйте `115200` бод.
- Не забывайте общий GND между камерой, приёмником и Arduino, и будьте внимательны с питанием, не подавайте большое напряжение на Arduino.
